# Ranjini P — Personal Portfolio (React + Vite)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed ([download here](https://nodejs.org/))

### Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open in browser
# http://localhost:5173
```

### Build for Production

```bash
npm run build
npm run preview
```
